# Partner Portal Demo

A modern Partner Portal designed in Figma and developed using React, TypeScript and Vite.

## Features

- Partner onboarding
- Customer management
- Risk reports
- Dashboard analytics
- Authentication flow
- Responsive UI

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Recharts

## Purpose

This project was built to demonstrate product design implementation, frontend architecture, and UI development skills.

This repository is private and shared only for interview evaluation.
